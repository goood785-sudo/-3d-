# Web 3D Home Planner

건축 평면도, 입면도, 단면도를 바탕으로 세대 내부를 3D로 구성하고, 별도 프로그램 설치 없이 웹에서 가구를 배치하며 공간을 검토하는 프로젝트입니다.

## 목표

- CAD(`DWG`/`DXF`) 또는 PDF 도면 입력
- 벽체, 바닥, 천장, 문, 창호, 기둥 및 붙박이 가구의 3D 변환
- 브라우저에서 세대 모델 확인 및 이동
- 실제 치수 기반 가구 배치, 회전, 교체 및 삭제
- 가구와 벽의 충돌, 동선 및 여유 공간 확인
- 배치안 저장, 비교 및 공유
- 아파트 단지와 세대 타입별 기본 모델 재사용

## 기본 방향

- 고객 화면: 설치가 필요 없는 웹 기반 2D/3D 공간 편집기
- 도면 처리: CAD 원본 우선, 벡터 PDF 지원, 스캔 PDF는 보정 절차 적용
- 3D 모델: 실측 단위와 구조화된 공간 데이터에 따라 결정론적으로 생성
- AI 활용: Astra를 도면 해석, 데이터 구조화, 생성 스크립트 작성 및 모델 검수에 활용
- 품질 원칙: AI가 임의로 형상을 추정하지 않고 도면 치수와 명시적인 가정에 근거해 생성

## 초기 MVP

1. 세대 타입 한 개의 도면을 입력한다.
2. 벽, 문, 창호 및 주요 붙박이 가구를 3D로 변환한다.
3. 웹에서 2D 평면과 3D 화면을 함께 제공한다.
4. 대표 가구 20~30종을 배치할 수 있게 한다.
5. 배치안 저장과 공유 링크를 제공한다.

## 입력자료 우선순위

1. `DWG` 또는 `DXF` 원본
2. 치수와 축척이 유지된 벡터 PDF
3. 스캔 PDF 또는 도면 이미지

평면도와 함께 입면도, 단면도, 창호도, 천장고, 단차 및 보 높이 자료가 있으면 모델 정확도가 높아집니다.

## 주의사항

생성 모델은 이사 전 가구 배치와 공간 검토를 위한 시각화 자료입니다. 구조, 법규, 시공 및 계약 치수를 확정하는 전문 설계도서를 대체하지 않습니다.
