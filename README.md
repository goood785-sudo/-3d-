# 101동 웹 3D 홈 플래너

부산 에코델타시티 공동31블럭 건축도면을 바탕으로 만든 브라우저 기반 공간 검토 프로토타입입니다. 별도 앱 없이 101동 기준층의 세대 타입을 고르고, 실제 크기의 가구를 배치해 볼 수 있습니다.

## 현재 범위

- 기준 도면: 동평면도 A-305, `101동 기준층(3~9층) 평면도`
- 단위세대 대조: A-201~220
- 101동 기준층 확인 타입: 110B, 110C, 119C
- 구조벽·경량벽·창호·문 위치 표시 전환
- 3D/평면 카메라 전환
- 소파·침대·식탁·냉장고 배치, 이동, 90도 회전, 삭제

## 실행

정적 웹사이트이므로 `dist` 폴더를 임의의 HTTP 서버로 제공하면 됩니다.

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

브라우저에서 `http://127.0.0.1:4173/`을 엽니다.

## 도면 처리 원칙

GstarCAD 2022로 DWG를 분석용 DXF로 변환한 뒤 필요한 선형만 경량 JSON으로 정리했습니다. 원본 DWG, 변환 DXF, 분석 이미지와 임시 도구는 저장소에 포함하지 않습니다.

벽체 높이 2.70m는 1차 가정값입니다. 단면도와 창호도를 추가 대조해 층고, 창턱, 문·창 개구부를 보정하는 것이 다음 단계입니다.
